## Frame_Lens-Project

# Project Overview
The idea for this project is to enhance patient service and expand its product offerings by integrating eyewear options from leading online retailers. Create clean, standardized datasets to support decision-making and improved eyewear choices.

# Dataset 

The data contains 150 sales records with information including:

- Product ID
- Product name
- Brand 
- Price
- Frame colour 
- Frame shape 
- Frame material 
- Gender
- Availability
- Product url
- Page number
- Source website
- Data type

## Tools Used

## Database Tables 

The data was organised into the following tables:
* Costumers
* Products
* Orders
* Order_items
* Deliveries

## Analysis 

The Project includes calculation for 
* Total revenue
* Total number of order
* Revenue by product
* Revenue by sales channel
* Delivery performance

## Project Objectives 

The main objectives are to:

1. Tack Business Sales:
   * Customer Purchasing Behavior
   * Product Performance
   * Revenue and order fulfilment

2. Organise the data:
   * Store the sales data in PostgreSQL
   * Organise the data into structured tables
   * Maintain the original dataset
   * Calculate important sales metrics
   * Use SQL queries to support business analysis
